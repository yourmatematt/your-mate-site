## SECTION 6 — Ranking rationale

### Title tag
**Why it should move:** The current title leads with "Web Development & AI Services" — neither "SEO agency" nor "digital marketing agency" appears. Google's ranking signal for "seo agency gippsland" is weak because the most heavily-weighted on-page element doesn't mention the query. New title puts the primary query in positions 1–3 of the title, which is where Google weights hardest.

**Risk:** The page currently ranks somewhere (not tracked, but probably page 3–4) for "ai services gippsland" and "web development gippsland". Dropping "AI" from the title (Variant B) may reduce visibility for "ai services gippsland" queries. Variant A keeps "AI" in the suffix, which mitigates this.

### Meta description
**Why it should move:** Meta descriptions don't directly affect ranking but strongly affect CTR. Current CTR is 0%. New description includes the buyer query verbatim in the first 5 words, plus a human signal ("Matt from Mallacoota") and a clear CTA. Expect CTR lift from 0% → 2–4% at current positions, which over time compounds into ranking improvements.

**Risk:** None meaningful — meta descriptions can be re-tested freely.

### H1
**Why it should move:** Current H1 is sr-only and reads "Web Development, SEO & AI Services" — "SEO" is buried in the middle. New H1 leads with "SEO" which is the primary target query. H1 is a secondary but still meaningful ranking signal, especially on a page where body copy is thin.

**Risk:** Low. H1 is sr-only — no visual change risk.

### Intro paragraph
**Why it should move:** The biggest single problem with the current page is thin body copy above the fold. Google has very little text to analyse for topical relevance. Adding 130 words of on-topic copy that includes "SEO agency", "Gippsland", "East Gippsland", "Mallacoota", "local SEO", "Google Maps", and buyer-intent phrases ("plumber Bairnsdale", "cafe Lakes Entrance") gives Google far more signal to rank the page for the whole cluster of Gippsland SEO/marketing queries — not just the exact title match.

**Risk:** None — this is purely additive copy in Matt's voice. It strengthens every query the page already ranks for.

### Internal links
**Why it should move:** The page currently has no inbound links from high-traffic blog posts with anchor text matching the target query. Google treats anchor text on internal links as a topical signal. Five new internal links with varied, query-matched anchors is a measurable boost for a page that's bouncing between pos. 17–35.

**Risk:** None. All anchors are natural, none are stuffed. Variety prevents any single anchor from looking manipulated.
