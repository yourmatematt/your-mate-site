HAMMOND PROPERTIES

Mallacoota's premier luxury holiday rentals

OVERVIEW

When Amelia from Hammond Properties came to us, her site wasn't doing her justice.

She runs Mallacoota's leading luxury holiday rentals — 15+ stunning homes, 500+ happy guests, and a 4.9-star rep that most businesses would kill for. But the old website? Clunky, slow, and nowhere near "luxury."

So, we rebuilt it from the ground up

YMA ROLE
WEBSITE DESIGN +

React 18 + TypeScript. Vite build with SWC for fast loads. shadcn/ui components. Custom luxury theme with Playfair Display and Inter fonts. Framer Motion animations. Hybrid SSG + SPA architecture for SEO.

SEO +

Static prerendering for 25 routes. Schema.org structured data for rich snippets. Dynamic canonical tags. Optimised meta descriptions. Legacy URL redirects mapped.

CONTENT COPYWRITING +

Property descriptions, blog posts, and marketing copy. All stored in Supabase with slug-based routing.

AI AUTOMATION +

Supabase Edge Functions for automated enquiry emails via Resend API. JWT-authenticated serverless endpoints.
